# 釐清問題

開支日期未指定時預設為「當天」,此「當天」以哪個時區判定?

# 定位

ERM:`expenses.expense_date` note「未指定時預設為當天」未定義時區基準。
Feature:「新增開支」的 Rule「開支日期未指定時預設為當天」及其 Example「未指定日期時開支日期為當天」。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 使用者裝置的本地時區(前端帶入預設值) |
| B | 伺服器/資料庫時間(UTC) |
| C | 固定 UTC+8(台灣時間) |
| Short | 提供其他簡短答案(<=5 字)|

# 影響範圍

- 預設日期由前端帶入或 DB default 決定(實作位置不同)
- 跨時區旅遊時深夜新增開支的日期歸屬
- 「未指定日期時開支日期為當天」Example 的驗證方式

# 優先級

Low
- 優化細節;作品集情境下影響有限,但答案決定實作位置

---
# 解決記錄

- **回答**:A - 使用者裝置的本地時區(前端帶入預設值)
- **更新的規格檔**:spec/erm.dbml
- **變更內容**:`expenses.expense_date` note 補上「以使用者裝置時區判定,由前端帶入預設值」
