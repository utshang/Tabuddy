# 釐清問題

開支金額(expenses.amount)是否有上限?

# 定位

ERM:`expenses.amount` note 僅定義「> 0」,未定義最大值。
Feature:「新增開支」的 Rule「金額為必填且必須大於 0」僅涵蓋下界。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 無上限(受資料型別範圍自然限制即可) |
| B | 有上限,例如 10,000,000,超過時操作失敗 |
| Short | 提供其他簡短答案(<=5 字)|

# 影響範圍

- `expenses.amount` 的邊界約束與表單驗證
- 是否需補充上界 Example
