# 釐清問題

編輯交通時間時，是否可以編輯交通工具的圖示（icon）欄位？

# 定位

Feature：編輯交通時間，Rule「成員可以編輯交通時間的交通工具」與 Rule「編輯交通時間可同時修改任意欄位組合」——目前所有步驟句型與資料表皆未包含 `icon` 欄位。
ERM：`transports.icon`（string，選填）已於新增交通時間階段定義，但編輯功能未同步。

（背景：`.clarify/resolved/features/新增交通時間_交通工具是否僅限四個固定枚舉值.md` 的補充修訂已明確列出待辦——本 feature 的欄位與步驟句型尚未同步補上 `icon`。）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可編輯，圖示為編輯交通時間的一般欄位，可單獨修改或與其他欄位組合修改（feature 所有資料表與步驟句型需補上 icon） |
| B | 不可單獨編輯；僅在將交通工具改為自訂名稱時可一併設定圖示，其餘情況不可改 |
| C | 不可編輯；圖示僅能在新增交通時間時設定，要更改須刪除後重新新增 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

決定 `編輯交通時間.feature` 是否需新增「成員可以編輯交通工具圖示」Rule 與對應 Example；所有既有 Example 的交通時間資料表是否補上 `icon` 欄位（與 `新增交通時間.feature` 的資料表格式一致）；影響編輯交通時間 API 的可更新欄位清單與前端編輯表單的欄位組成。相關已解決項目：[[新增交通時間_交通工具是否僅限四個固定枚舉值]]。另與 [[transports_mode為預設選項時icon是否必須為空]] 有前置依賴關係（需先確定 icon 可否編輯）。

# 優先級

High
- 此為已知的規格同步待辦，未釐清前本 feature 的步驟句型與資料表格式無法定稿，直接阻礙編輯交通時間功能的完整定義。

# 解決記錄

- **回答**：B - 不可單獨編輯；僅在將交通工具改為自訂名稱時可一併設定圖示，其餘情況不可改
- **更新的規格檔**：spec/features/編輯交通時間.feature, spec/erm.dbml
- **變更內容**：所有 Example 的交通時間資料表補上 `icon` 欄位（與新增交通時間格式一致）；新增 Rule「變更交通工具時可一併設定圖示」（自訂名稱＋圖示成功案例）與 Rule「圖示不可單獨編輯」（單獨改圖示操作失敗案例）；`transports.icon` note 補上「僅能在新增交通時間或變更 mode 時一併設定，不可單獨編輯」

---
# 修訂記錄（2026-07-15）

- **修訂後回答**：A - 可自由編輯；圖示是編輯交通時間的一般欄位，僅適用於自訂交通工具（mode 非預設選項），可單獨修改也可與交通工具名稱一併修改
- **更新的規格檔**：spec/erm.dbml, spec/features/編輯交通時間.feature
- **變更內容**：`transports.icon` note 改為「僅適用於自訂交通工具（mode 非預設選項），編輯交通時間時可與名稱一併或單獨修改」；Feature 中原本的 Rule「圖示不可單獨編輯」移除，「變更交通工具時可一併設定圖示」更名為「自訂交通工具的名稱與圖示皆可編輯」並新增 Example「成員單獨修改自訂交通工具的圖示」；「交通工具改為預設選項時圖示自動清除」規則維持不變
