# 釐清問題

行程備註（`activities.note`）是否有字數上限？

# 定位

ERM：`activities.note`（`spec/erm.dbml` 第 67 行）僅註記「選填」，未定義長度限制。
Feature：`新增行程.feature` 與 `編輯行程.feature` 皆未涵蓋備註長度邊界的 Example。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 無長度限制 |
| B | 有長度上限（需另行指定字數） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/erm.dbml`：`activities.note` 的 note 是否需補充長度限制
- `spec/features/編輯行程.feature` 與 `新增行程.feature`：若有長度上限，需新增對應驗證 Rule 與 Example
- 資料庫欄位型別：`note` 是否需限制為 `varchar(n)` 或使用 `text`

# 優先級

Low
- Low：屬於邊界細節，多數情況下不影響核心功能或資料建模正確性

---
# 解決記錄

- **回答**：A - 無長度限制
- **更新的規格檔**：`spec/erm.dbml`
- **變更內容**：`activities.note` 的 note 補充「無長度限制」
