# 釐清問題

使用者執行「編輯行程」時，是否可以在同一次操作中同時修改多個欄位（例如同時修改 name 與 note），或每次編輯僅能變更單一欄位？

# 定位

Feature：`編輯行程.feature` 目前僅有的 Example 一次只修改 name 一個欄位。對照 `編輯旅程.feature` 已明確定義 Rule「編輯旅程可同時修改任意欄位組合」，`編輯行程` 尚無對應規則。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可同時修改任意欄位組合（比照編輯旅程） |
| B | 每次編輯僅能修改單一欄位 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/編輯行程.feature`：需新增「編輯行程可同時修改任意欄位組合」對應 Rule 與 Example（若選 A）
- API/Server Action 設計：編輯行程的 mutation 介面是否接受多欄位 partial update
- 與 [[編輯行程_可編輯欄位是否包含GoogleMap連結停留時間與備註]] 為相關聯釐清項目，建議一併處理

# 優先級

Medium
- Medium：影響規則完整性與 API 設計，但不影響核心資料模型正確性

---
# 解決記錄

- **回答**：A - 可同時修改任意欄位組合（比照編輯旅程）
- **更新的規格檔**：`spec/features/編輯行程.feature`
- **變更內容**：新增「編輯行程可同時修改任意欄位組合」Rule 及同時修改 name、google_map_url、duration_minutes、note 四欄位的 Example
