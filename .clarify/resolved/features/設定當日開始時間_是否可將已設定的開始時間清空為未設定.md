# 釐清問題

已設定開始時間的日期，使用者是否可以將其清空（改回未設定狀態）？

# 定位

ERM：`days.start_time`（note：「當天行程開始時間（HH:MM），選填」，代表可能為空值）。
Feature：設定當日開始時間 — 目前 Rule「成員可以設定當日的開始時間」只涵蓋設定為某個時間值的情境，未涵蓋「清空為未設定」的操作與其後置條件。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可以清空，清空後 `start_time` 為空值，需新增對應 Rule + Example |
| B | 不可清空，一旦設定就必須有值，只能修改為其他時間 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/設定當日開始時間.feature`：可能需新增 Rule + Example
- `spec/features/行程時間軸.feature`：若允許清空，需確認清空後時間軸計算的行為（見另一釐清項目）

# 優先級

Medium
- Medium：影響 API/資料操作設計完整性，但不阻礙核心新增流程

# 解決記錄

- **回答**：B - 不可以清空，一旦設定了就一定要有值，只能改成別的時間
- **更新的規格檔**：spec/features/設定當日開始時間.feature、spec/erm.dbml
- **變更內容**：於 `設定當日開始時間.feature` 新增 Rule「已設定的開始時間不可清空為未設定」及對應 Example（嘗試清空時操作失敗）；於 `erm.dbml` 的 `days.start_time` note 補充「一旦設定後不可清空為未設定，僅能改為其他時間」
