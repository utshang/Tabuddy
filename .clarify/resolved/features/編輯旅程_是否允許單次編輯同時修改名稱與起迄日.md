# 釐清問題

編輯旅程的操作是否接受單次同時修改名稱與起迄日（任意欄位組合），或名稱與起迄日必須是各自獨立的編輯操作？

# 定位

Feature：編輯旅程 — 現有 Example 的 When 步驟皆寫作「執行編輯，將名稱改為 X」，僅示範單一欄位（名稱）的修改，未定義是否可於同一次操作中同時提供起日、迄日等其他欄位，也未有僅編輯起迄日、不改名稱的 Example。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 是，編輯操作接受任意欄位組合（名稱、起日、迄日可單獨或同時修改），未提供的欄位維持原值 |
| B | 否，名稱與起迄日為各自獨立的編輯操作（如分開的表單或 API 呼叫） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/編輯旅程.feature`：When 步驟語法與 Example 設計（是否需涵蓋多欄位同時編輯的情境）
- 前端編輯表單 UI 設計（單一表單 vs 分開表單）、server action 參數設計

# 優先級

Medium
- Medium：影響 UI/API 設計與 Example 完整性，但不涉及核心資料建模或跨實體資料完整性風險

---
# 解決記錄

- **回答**：A - 是，編輯操作接受任意欄位組合，未提供的欄位維持原值
- **更新的規格檔**：`spec/features/編輯旅程.feature`
- **變更內容**：新增 Rule「編輯旅程可同時修改任意欄位組合」及對應 Example（同時修改名稱、起日與迄日）
