# 釐清問題

設定當日開始時間時，若輸入值不符合 HH:MM 格式（例如 "25:70"、"8:0"、純文字），操作應如何處理？

# 定位

ERM：`days.start_time`（note：「當天行程開始時間（HH:MM），選填」）。
Feature：設定當日開始時間 — Rule「成員可以設定當日的開始時間」目前所有 Example 皆使用合法的 HH:MM 值（"08:00"、"09:00"），未涵蓋格式不合法的情境，也未定義任何前置條件規則檢查格式。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 格式不符時操作失敗，需新增對應前置條件 Rule + Example |
| B | 系統不需後端額外檢查，因前端 UI 為時間選擇器（time picker），不會產生不合法格式 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/設定當日開始時間.feature`：可能需新增前置條件 Rule
- `spec/erm.dbml`：`days.start_time` note 可能需補充格式限制說明
