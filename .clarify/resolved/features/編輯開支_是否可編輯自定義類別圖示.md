# 釐清問題

編輯開支時，是否可修改自定義類別的圖示（category_icon）？可否不改類別名稱而單獨修改圖示？

# 定位

- Feature：`編輯開支.feature` Rule「成員可以編輯開支的類別，類別不得為空」——僅涵蓋類別名稱，未提及 category_icon
- ERM：`expenses.category_icon` note 僅說明「僅適用於自定義類別」，未如 `transports.icon` 明文「編輯時可與名稱一併或單獨修改」
- 相關已解決項目：`resolved/features/編輯交通時間_是否可編輯交通工具圖示.md`（交通工具圖示已決議為可編輯，本題確認開支類別是否比照）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 比照交通工具圖示：可與類別名稱一併或單獨修改（並於 ERM note 補上對等說明） |
| B | 僅能在選擇／新增自定義類別時一併設定，不可事後單獨修改 |
| C | 編輯開支不可修改圖示 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

- `編輯開支.feature` 是否需補類別圖示相關 Rule 與 Example
- `erm.dbml` 的 `expenses.category_icon` note
- 編輯開支表單的欄位設計
- 註：「category 改回預設選項時系統自動清除 category_icon」已為 ERM 既定不變條件，不在本題範圍

# 解決記錄

- **回答**：A - 比照交通工具圖示：可與類別名稱一併或單獨修改
- **更新的規格檔**：spec/features/編輯開支.feature、spec/erm.dbml
- **變更內容**：新增 Rule「自定義類別的名稱與圖示皆可編輯」與 2 個 Example（一併設定圖示、單獨修改圖示）；`expenses.category_icon` note 補上「編輯開支時可與類別名稱一併或單獨修改」（與 transports.icon 對等）
