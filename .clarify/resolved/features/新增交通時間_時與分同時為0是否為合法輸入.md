# 釐清問題

當「時」與「分」同時為 0（即零時長的交通時間）時，是否為合法輸入？

# 定位

Feature：新增交通時間，Rule「時為必填且 >= 0」與 Rule「分為必填且 >= 0 且 < 60」的交集（兩者皆標記 #TODO）
ERM：`transports` 目前無此項跨屬性不變條件

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 合法，允許新增 0 時 0 分的交通時間（例如同棟建築內移動，仍想記錄交通工具但時間可忽略不計） |
| B | 不合法，時與分至少一者須 > 0，否則操作失敗 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

影響 `新增交通時間.feature` 是否需新增一條跨欄位 Rule 與對應 Example（零時長案例）；若決議為不合法，需同步在 `spec/erm.dbml` 的 `transports` Note 補上此跨屬性不變條件；亦影響 `編輯交通時間.feature` 的一致性（編輯後是否可將時與分同時改為 0）。

# 優先級

Medium
- 屬於邊界組合案例，答案會決定是否需要額外的跨欄位驗證邏輯。

---
# 解決記錄

- **回答**：A - 合法，允許新增 0 時 0 分的交通時間
- **更新的規格檔**：spec/features/新增交通時間.feature
- **變更內容**：在 Rule「成功新增後交通時間出現在對應行程之後」下新增 Example「成員成功新增時與分皆為 0 的交通時間」，明確驗證此邊界情境為合法輸入；erm.dbml 不需新增跨屬性不變條件（決議為無此限制）
