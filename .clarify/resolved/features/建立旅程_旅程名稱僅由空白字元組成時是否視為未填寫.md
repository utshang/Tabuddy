# 釐清問題

旅程名稱輸入內容僅由空白字元組成（如 " "）時，是否應視為未填寫並操作失敗？

# 定位

Feature：建立旅程 — Rule「旅程名稱為必填」目前僅以空字串 `""` 驗證必填情境，未定義輸入純空白字元時的處理方式。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 視為未填寫，前後端皆需 trim 後再判斷是否為空，空白字串操作失敗 |
| B | 視為合法輸入，允許以空白字元作為旅程名稱 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/建立旅程.feature`：新增對應 Example
- 表單驗證（Zod schema）需對應加上 trim 規則

# 優先級

Medium
- Medium：屬輸入驗證邊界情況，不影響核心資料建模，但影響表單驗證邏輯與測試完整性

---
# 解決記錄

- **回答**：A - 視為未填寫，前後端皆需 trim 後再判斷是否為空，空白字串操作失敗
- **更新的規格檔**：`spec/features/建立旅程.feature`、`spec/erm.dbml`
- **變更內容**：
  - `建立旅程.feature` 於「旅程名稱為必填」Rule 下新增 Example（名稱僅有空白字元時操作失敗）
  - `erm.dbml` 的 `trips.name` Note 補充「trim 後不可為空字串」
