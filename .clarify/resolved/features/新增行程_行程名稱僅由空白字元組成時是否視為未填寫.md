# 釐清問題

行程名稱輸入內容僅由空白字元組成（如 " "）時，是否應視為未填寫並操作失敗？

# 定位

ERM：`activities.name`（"行程名稱，必填"，未如 `trips.name` 明確註明 trim 規則）。
Feature：新增行程 — Rule「行程名稱為必填」目前僅以空字串 `""` 驗證必填情境，未定義輸入純空白字元時的處理方式。
相關已解決項目：[[建立旅程_旅程名稱僅由空白字元組成時是否視為未填寫]]（`trips.name` 已採用「trim 後判斷是否為空」的做法）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 比照旅程名稱，視為未填寫，前後端皆需 trim 後再判斷是否為空，操作失敗 |
| B | 視為合法輸入，允許以空白字元作為行程名稱 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/新增行程.feature`：新增對應 Example
- `spec/erm.dbml`：`activities.name` 說明可能需補充 trim 規則
- 表單驗證（Zod schema）

# 解決記錄

- **回答**：A - 比照旅程名稱，視為未填寫，前後端皆需 trim 後再判斷是否為空，操作失敗
- **更新的規格檔**：`spec/features/新增行程.feature`、`spec/erm.dbml`
- **變更內容**：
  - `新增行程.feature` 於「行程名稱為必填」Rule 下新增 Example（名稱僅有空白字元時操作失敗）
  - `erm.dbml` 的 `activities.name` note 補充「trim 後不可為空字串」
