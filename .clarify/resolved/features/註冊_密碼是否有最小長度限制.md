# 釐清問題

註冊時密碼是否有最小長度限制？

# 定位

Feature：註冊 — Rule（缺失）  
目前 `spec/features/註冊.feature` 只有「Rule: 密碼為必填」，未定義長度限制。  
`spec/erm.dbml` 的 users 實體亦無密碼強度說明（password 由 Supabase Auth 管理）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 是，密碼至少 8 個字元（需新增獨立 Rule） |
| B | 是，沿用 Supabase 預設（最少 6 個字元） |
| C | 否，只驗證必填（維持現狀） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/註冊.feature`：若選 A 或 B，需新增 Rule + Example
- `src/lib/validations/auth.ts`：`signupSchema` 的 password 需對應調整 `.min(N)`

# 優先級

Medium
- Medium：影響密碼邊界條件的測試設計；Supabase 本身有預設限制，需與規格對齊

---
# 解決記錄

- **回答**：B — 沿用 Supabase 預設，密碼至少 6 個字元
- **更新的規格檔**：`spec/features/註冊.feature`
- **變更內容**：新增 Rule「密碼長度至少 6 個字元」及對應 Example
