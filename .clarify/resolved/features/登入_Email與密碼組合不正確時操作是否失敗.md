# 釐清問題

帳號不存在或密碼錯誤時，系統應如何處理？

# 定位

Feature：登入 — 缺少 Pre-condition Rule「Email 與密碼組合必須有效」

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 操作失敗，且不區分「帳號不存在」與「密碼錯誤」（統一回傳相同錯誤，防止帳號枚舉） |
| B | 操作失敗，區分兩種情境並顯示不同錯誤訊息 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

- `登入.feature`：需新增一條 Pre-condition Rule 與對應 Example
- 前端 UI：錯誤訊息文案設計（區分或不區分）

# 優先級

High
- 這是登入最常見的失敗情境，規格完全缺失此 Rule 會導致實作無所依據

---
# 解決記錄

- **回答**：B — 區分兩種情境，帳號不存在與密碼錯誤分別顯示不同錯誤訊息
- **更新的規格檔**：spec/features/登入.feature
- **變更內容**：新增兩條 Pre-condition Rule：「Email 必須存在於系統中」與「密碼必須正確」，各附一個 Example
