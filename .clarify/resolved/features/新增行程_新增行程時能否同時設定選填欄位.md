# 釐清問題

新增行程時是否可同時設定選填欄位（GoogleMap 連結、停留時間、備註），或僅能於新增後透過「編輯行程」設定？

# 定位

ERM：`activities.google_map_url`、`activities.duration_minutes`、`activities.note`（皆為選填屬性）。
Feature：新增行程 — 三條 Rule 與 Example 僅涉及「名稱」欄位，未提及新增當下能否一併輸入其餘選填欄位。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 新增行程時僅能輸入名稱，其餘選填欄位須於新增後透過「編輯行程」設定 |
| B | 新增行程時可一併輸入名稱與所有選填欄位 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- `spec/features/新增行程.feature`：When 步驟參數與 Example 是否需擴充
- 表單/UX 設計：新增與編輯行程的 modal/表單是否共用同一組欄位

# 優先級

Medium
- Medium：影響表單設計與測試涵蓋範圍，但不影響核心資料模型正確性（欄位本身已定義為選填）

---
# 解決記錄

- **回答**：B - 新增行程時可一併輸入名稱與所有選填欄位
- **更新的規格檔**：`spec/features/新增行程.feature`
- **變更內容**：
  - 新增 Rule「新增行程時可一併填寫選填資訊」，含 Example（新增時同時填寫 GoogleMap 連結、停留時間、備註）
