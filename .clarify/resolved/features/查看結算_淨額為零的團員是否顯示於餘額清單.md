# 釐清問題

淨額為 0 的團員(含未參與任何開支的團員)是否顯示於餘額清單中?

# 定位

Feature:`查看結算.feature` Rule「每位團員的淨額 = 他付出的總金額 − 他被分攤的總金額」——現有 Example 中所有團員均有非零淨額,缺少「團員存在但未付款也未被分攤」或「付出恰等於被分攤」的類別邊界 Example。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 顯示全部團員,淨額 0 照列——餘額清單即團員清單,完整呈現 |
| B | 僅顯示淨額非 0 的團員 |
| Short | 提供其他簡短答案(<=5 字) |

# 影響範圍

- `查看結算.feature`:需補「未參與任何開支的團員淨額為 0 且(不)顯示」的 Example
- Rule「所有團員的淨額總和為 0」的「所有團員」語意(是否含未參與者)
- 餘額清單 UI 呈現與查詢實作(以 trip_members 為基底 left join,或僅聚合 expenses)

# 優先級

Medium
- 影響類別邊界與 UI 呈現,不阻礙演算法定義

---
# 解決記錄

- **回答**:A - 顯示全部團員,淨額 0 照列(餘額清單即團員清單;「所有團員」語意包含未參與者;實作以 trip_members 為基底)
- **更新的規格檔**:spec/features/查看結算.feature
- **變更內容**:新增 Rule「餘額清單列出旅程所有團員,含淨額為 0 者」與 Example「未參與任何開支的團員淨額為 0 且列於餘額清單」(四人旅程,團員 D 未付款亦未被分攤,淨額 0 照列)。
